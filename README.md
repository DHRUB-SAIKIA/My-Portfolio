# Dhruba Saikia — Creative Portfolio

A modern, interactive portfolio website for Dhruba Saikia — Web Designer, UI/UX Designer, Graphic Designer, Cinematographer, and Photographer.

![Portfolio Preview](https://raw.githubusercontent.com/DHRUB-SAIKIA/My-Portfolio/main/public/images/graphic1.png)

## 🚀 Features

- **Interactive Canvas Background**: Frame-scrubbing smooth background animations tailored for high visual engagement.
- **Smooth Scrolling & Micro-Animations**: Built with [Lenis](https://lenis.darkroom.engineering/) for buttery smooth scrolling mechanics.
- **Showcase Sections**: Dedicated sections for Web Design, UI/UX, Graphic Design, Cinematography, and Photography.
- **Automated GitHub Pages Deployment**: Fully configured GitHub Actions workflow (`.github/workflows/deploy.yml`) for automated building and deployment.

## 🛠️ Tech Stack

- **Framework / Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: Modern Vanilla CSS (Custom Design System, Glassmorphism, Responsive Grid & Flexbox)
- **Smooth Scroll**: Lenis Scroll API
- **Fonts**: Google Fonts (`Outfit`, `Bebas Neue`, `Alex Brush`)
- **CI/CD**: GitHub Actions & `gh-pages`

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/DHRUB-SAIKIA/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages manually**:
   ```bash
   npm run deploy
   ```
